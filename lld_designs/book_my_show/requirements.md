**Requirements**

**Funtional requirement**
1. Browse movies
2. Search movies by city/date
3. View theatres for a movie
4. View available shows
5. View seat layout
6. Select seats
7. Lock seats temporarily
8. Make payment
9. Confirm booking
10. Cancel booking
11. Receive booking notification

Non Functional requirements

1. Prevent double booking
2. Highly available
3. Horizontally scalable
4. Low response time
5. Fault tolerant
6. Idempotent payment

Assumptions

- Payment gateway already exists.
- Authentication is outside the scope.
- Seat layout is already configured.
- One booking belongs to one user.
